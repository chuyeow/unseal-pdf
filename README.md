# Unseal

Unseal is a local-first PWA for removing password protection from PDFs in the browser with `qpdf` compiled to WebAssembly.

Live at [unseal-pdf.vercel.app](https://unseal-pdf.vercel.app). Pushes to `main` deploy automatically.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
